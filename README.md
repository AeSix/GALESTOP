# GALESTOP
Google AI Live Entry Suggestive Text Omitter &amp; Preventer - a [greasemonkey | tampermonkey] usercript created for use with Firemonkey on Firefox to... well, prevent in-line suggestive / predictive *ghost* text from showing.

I made this to be able to type distraction free.  Predictive text and suggestions are like a gale-force wind of chaos against my focus and concentration - more times than I care to admit, I've lost track of what I was researching, looking for... doing. Infact, even with Google AI doing the coding, it still took me the better part of 4 horus to get the script working correctly - and another hour to set up the github repo and polish things up.  I do not remember what I was attempting to do, specifically, when I got on this tangent. 

I hope this brings others contentment where there once was despair. If does not break - and I remember it, I will upload it to a userscript repo as well. I'd love for there to be other contributors, more features maybe - I don't know what could possibly be added, but if I did, I probably would have added it (and still be at it...)
